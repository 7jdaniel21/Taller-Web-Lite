# AutoTaller Lite

## Descripción del proyecto

AutoTaller Lite es una aplicación web desarrollada para facilitar la gestión administrativa y operativa de un taller mecánico. Su objetivo es centralizar la información de los clientes, vehículos, mecánicos, servicios, órdenes de trabajo y facturación, permitiendo un mejor control y seguimiento de las actividades del taller.

El sistema busca optimizar los procesos internos, reducir el manejo manual de información y facilitar la consulta de registros mediante una interfaz sencilla, intuitiva y funcional.

## Funcionalidades previstas

- Autenticación y gestión de usuarios.
- Gestión de clientes, vehículos y mecánicos.
- Administración de servicios y órdenes de trabajo.
- Control de facturación.
- Historial de estados de las órdenes.
- Registro de inspecciones y evidencias.
- Gestión de observaciones.

## Tecnologías utilizadas

- C#.
- ASP.NET Core MVC.
- .NET 10.
- Entity Framework Core.
- SQL Server.
- HTML, CSS, JavaScript y Bootstrap.
- Git y GitHub.

## Metodología de desarrollo

El proyecto se desarrolla mediante la metodología ágil Scrum, distribuyendo las actividades en cuatro Sprints y asignando responsabilidades específicas a cada integrante del equipo. Se utiliza GitHub Projects para gestionar las tareas, controlar los avances y facilitar el trabajo colaborativo.
